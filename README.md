# Prepress Colour Management Interactive Labs v2.0

**Interactive simulation-based laboratories for teaching prepress colour management**

Prepress Colour Management Interactive Labs is a browser-based learning environment for graphic arts, printing, and visual communication education. It makes normally hidden colour-management processes visible through interactive simulation-based laboratories.

## How to Run

No installation or server is required.

1. Download and extract the package.
2. Open `index.html` in a modern browser.
3. Use the sidebar to move through the interactive laboratories.
4. Open `manual.html` from the application or directly in the browser for scientific and educational guidance.

## Laboratory Coverage

The platform includes nine interactive laboratories:

- Additive colour synthesis.
- Subtractive colour synthesis.
- CMYK separation and screen-angle logic.
- Total Area Coverage / Total Ink Limit.
- Colour spaces and gamut boundaries.
- Grey Component Replacement and Under Colour Removal.
- Tone Value Increase.
- ICC rendering intents with Black Point Compensation.
- ISO-oriented soft-proofing logic.

## Educational Scope

The tool is designed for technical/vocational education and first-year higher education in graphic arts, printing, and visual communication. It supports classroom demonstration, guided laboratory work, and self-paced exploration.

The simulations are educational heuristics. They are intended to make colour-management logic inspectable and teachable, not to replace certified production workflows, ICC engines, spectrophotometric measurement, or contract-proofing systems.

## Technical Notes

- Technology: HTML5, CSS, JavaScript.
- Architecture: Static client-side application.
- Dependencies: Google Fonts loaded from public CDN.
- Data: Local observation notes are stored in the browser.
- Browser support: Modern versions of Chrome, Firefox, Edge, and Safari.
