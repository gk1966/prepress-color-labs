Prepress Color Labs

Author: Georgios Korakakis
Affiliation: University of West Attica (UNIWA), Department of Graphic Design and Visual Communication

Description

Prepress Color Labs is a real-time, client-side simulation engine for prepress colorimetry.
It models RGB and CMYK workflows, including additive and subtractive synthesis, gamut mapping, tone value increase (TVI), and total area coverage (TAC), using heuristic methods in CIELAB space.

Usage

Open index.html in a modern web browser (Chrome, Firefox, or Edge).
