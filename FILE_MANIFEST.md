# File Manifest

This folder contains the Zenodo v2 upload package for Prepress Colour Management Interactive Labs.

| File | Purpose |
|---|---|
| `index.html` | Main interactive laboratory application. |
| `manual.html` | User, scientific, and educational manual. |
| `README.md` | General description, usage, citation, and license notes. |
| `CITATION.cff` | Machine-readable citation metadata. |
| `LICENSE` | License statement: MIT for software code; CC BY 4.0 for documentation. |
| `CHANGELOG.md` | Release notes. |
| `.zenodo.json` | Optional Zenodo/GitHub metadata file. |
| `ZENODO_UPLOAD_FIELDS.md` | Suggested fields to paste into the Zenodo web form. |

Recommended upload method: upload the ZIP file generated from this folder.
